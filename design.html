Para el texto de lectura de esta página se usa #6B6B6B en modo claro (5.19:1), porque el gris del token no alcanza AA a tamaños pequeños. El token sigue mostrado tal cual en la paleta. Con el azul pasa lo mismo: #0088CC queda en 3.80:1, así que el texto de los enlaces usa #0077B3, un paso más oscuro del mismo tono (4.77:1). El color de marca se conserva en la paleta y en los elementos gráficos. El naranja de los rótulos pequeños usa #C63C0A (4.84:1 sobre fondo alterno) por la misma razón.

05

Elevation & Depth

El diseño es mayormente plano. La sombra aparece solo cuando hay interacción o apilamiento; nunca como decoración. En oscuro, la profundidad se hace con superficies.

Nunca se supera 0 8px 24px. En modo oscuro las sombras se sustituyen por un escalón de superficie: carbón medio para tarjetas y carbón oscuro para capas elevadas.

Motivo de marca

El búho es el motivo de la marca. Se construye con el degradado naranja y se usa como sello, nunca como fondo que compita con la lectura.

08

Do's and Don'ts

Las reglas que mantienen el sistema coherente. Si una decisión no aparece aquí, se resuelve con los tokens, no con el gusto del momento.

Sí

  • ✓Usa primary-strong como fondo de los botones con texto blanco y reserva el naranja de marca para títulos, íconos y acentos.
  • ✓Mantén 20px como tamaño base del cuerpo en escritorio; nunca bajes de 16px.
  • ✓Aplica 48–92px de espaciado vertical entre secciones mayores.
  • ✓Usa PT Sans para cuerpo y navegación, y Raleway Black solo para títulos de nivel superior.
  • ✓Combina el naranja con fondos blancos y gris claro para máximo contraste.
  • ✓Usa botones de ícono circulares para enlaces sociales y acciones secundarias.
  • ✓Mantén tarjetas y componentes a 0px de radio para una apariencia nítida.
  • ✓Implementa los estados hover con cambios de color o subrayados, nunca con opacidad sola.

No

  • ✕No uses el naranja y el azul juntos en un mismo elemento interactivo; elige uno.
  • ✕No uses sombras más profundas que 0 8px 24px.
  • ✕No uses grises más claros que on-surface-muted para texto.
  • ✕No apliques tipografías serif en la jerarquía principal.
  • ✕No hagas botones menores a 32px (circulares) o 40px de alto (rectangulares).
  • ✕No escondas navegación crítica tras menús desplegables en móvil sin necesidad.
  • ✕No uses imágenes de fondo o texturas que compitan con la legibilidad.
